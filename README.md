# NEXORA

### Think. Share. Discover.

NEXORA is an AI-powered social networking platform inspired by modern microblogging platforms.

## Vision
To build a scalable social network that combines social interaction with intelligent AI-powered content discovery.

## Core Technologies

- Next.js
- React
- TypeScript
- Python
- Django REST Framework
- PostgreSQL
- Redis
- Machine Learning

## Planned Features

- User authentication and profiles
- Posts, replies, likes and reposts
- Personalized content feeds
- AI-powered recommendations
- Semantic search
- AI content assistant

## Project Status

Currently in the initial development and environment setup phase.

## Objective

Building a real-world social networking product while developing practical software engineering and AI/ML skills.
